Создай современный, адаптивный и эстетичный фронтенд для музыкального Telegram Mini App (TMA) на React (JSX/TSX) и Tailwind CSS в стиле Native Telegram UI.

======================================================================
1. ДИЗАЙН-СИСТЕМА И ЭСТЕТИКА (TELEGRAM UI STYLE)
======================================================================
- Использовать CSS-переменные Telegram WebApp: `var(--tg-theme-bg-color)`, `var(--tg-theme-text-color)`, `var(--tg-theme-button-color)` или классы Tailwind с адаптацией под темную тему по умолчанию (Slate/Zinc/Neutral 900+).
- Кастомные акцентные цвета для медиатек (динамическая подсветка):
  * Spotify: Неоново-зеленый (#1DB954)
  * Яндекс.Музыка: Ярко-желтый (#FFCC00)
  * YouTube Music: Красный (#FF0000)
- Закругления карточек: `rounded-2xl` или `rounded-3xl`, стеклянный эффект (backdrop-blur, glassmorphism), минимализм, отсутствие громоздких рамок.

======================================================================
2. КЛЮЧЕВЫЕ ЭКРАНЫ И ИНТЕРФЕЙС
======================================================================

1. Шапка (Header):
   - Профиль пользователя с аватаркой из Telegram.
   - Статус подключения хранилища: плашка "Канал привязан" (зеленый индикатор) или "Привязать канал" (красный аларм).
   - Быстрый переключатель активного сервиса (Табы: "Все", "Spotify", "Яндекс", "YouTube").

2. Экран подключения/инструкции (Modal / Banner):
   - Если канал не привязан (`NO_ACTIVE_GROUP`): выводить красивый баннер с кнопкой "Как привязать канал" (пошаговая инструкция добавления бота в админы).

3. Поисковая строка и Фильтры:
   - Умный инпут поиска треков и плейлистов с иконкой и кнопкой очистки.
   - Горизонтальный скролл тегов-чипсов (например: "Мой кеш", "Плейлисты", "Любимое", "Недавно прослушано").

4. Список треков (Track List):
   - Сетка/список карточек треков:
     * Обложка альбома (квадратная, со скруглением).
     * Название трека и исполнитель.
     * Небольшой бейдж-иконка источника (Spotify / Yandex / YT).
     * Статус кеша: иконка "Облако/Telegram" (если трек уже выгружен в канал) или "Скачать" (если еще не кеширован).
     * Кнопка дополнительных опций (`...`): замена аудиозаписи, удаление из кеша, переход в Telegram-пост.

5. Полный плеер (Full-screen Player / Bottom Sheet):
   - Выезжающий снизу оверлей с возможностью свайпа вниз (Drawer/BottomSheet):
   - Большая обложка альбома с мягким свечением (drop-shadow/glow) в цвет обложки.
   - Красивый Прогресс-бар (Seek bar) с текущим временем и общей длительностью.
   - Кнопки управления: Play/Pause, Next, Prev, Shuffle, Repeat.
   - Динамический визуализатор звука (анимированные эквалайзер-полоски).

6. Мини-плеер (Sticky Bottom Player):
   - Закрепленная снизу плашка плеера (над навигацией), которая видна всегда во время скролла.
   - Краткая информация (мини-обложка, название, Play/Pause, клик разворачивает полный плеер).

======================================================================
3. СОСТОЯНИЯ И АНИМАЦИИ (STATES & UX)
======================================================================
- Использовать `framer-motion` или Tailwind-анимации для плавных переходов между экранами и разворачивания плеера.
- Состояния загрузки (Skeletons / Loaders) во время выгрузки трека в Telegram-канал.
- Обработка ошибок (Toast-уведомления) при сбоях выгрузки или отсутствии связи с бэкендом.

======================================================================
ТРЕБОВАНИЯ К КОДУ:
======================================================================
1. Предоставь чистый компонентный код на React (Next.js / Vite) с использованием Lucide React для иконок и Tailwind CSS.
2. Сделай код модульным: выдели компоненты `Header`, `TrackItem`, `MiniPlayer`, `FullPlayer`, `StorageBanner`.
3. Реализуй моковые данные (mock state) для демонстрации работы плеера и переключения статуса кеширования.
